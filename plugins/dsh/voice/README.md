# Banter voice for dsh

A dsh plugin that adds Banter's voice mode to dsh's web UI: voice controls in the composer, spoken replies, and a settings page.

The documentation is in [docs/dsh-voice/](https://github.com/arvindvenkataramani/banter/tree/main/docs/dsh-voice):

- [Overview](https://github.com/arvindvenkataramani/banter/blob/main/docs/dsh-voice/README.md): the controls, their colours and the mic shortcut.
- [Setup](https://github.com/arvindvenkataramani/banter/blob/main/docs/dsh-voice/setup.md): build, install into a dsh profile, start dsh.
- [Settings](https://github.com/arvindvenkataramani/banter/blob/main/docs/dsh-voice/settings.md): every setting on the plugin's page.

To build and install: `bun run build`, then `bun run install-profile <profile> <banter-server-url>`.
