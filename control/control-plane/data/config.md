# config.json

`config.json` holds the control plane's gateway credentials and voice settings. Edit it directly; the example beside this file, `config.example.json`, shows the shape.

Every field is documented in the configuration reference: <https://github.com/arvindvenkataramani/banter/blob/main/docs/reference/configuration.md>

In a checkout of the repository, it is at `docs/reference/configuration.md`, and from this folder at `../../../docs/reference/configuration.md`.
